# 活动图书语料检索与 Rerank 评测（120 题版，2026-10-05）

## 范围与可复现数据

本轮使用已激活的本地图书语料 heritage-books-v1：10 本书、7,688 个 book:* 片段。documents.jsonl 的 SHA-256 为：


图书正文未提交到 Git；复现需要持有同一语料文件及相同哈希。运行时 Git HEAD 为 35d530ca177f34aab1835141a1bd03b14b7bdc0a，报告运行时间为 2026-10-05T15:55:33Z。

题集 [retrieval-books-v1.jsonl](../data/evaluation/retrieval-books-v1.jsonl) 共 120 条：

| 类型 | 数量 | 判分方式 |
| --- | ---: | --- |
| 直问 | 60 | 以标注片段 ID 是否进入前 k 为准。 |
| 改写问法 | 40 | 同上，用于观察不完全复述资料时的检索表现。 |
| 库外题 | 20 | 本轮未接入拒答模块，仅保留在结果中，拒答率不参与召回率分母。 |
| 可回答题合计 | 100 | Recall@1/3/5、MRR 与 Top-15 候选召回率的分母。 |

每条可回答题都有答案、book:* 片段 ID、页码和原文短引文。校验器检查题目 ID 唯一性、片段存在性、所属语料版本、页码、正文哈希及引文存在性；检索失败的题目不允许从题集中删除。

可回答题覆盖全部 10 本书，但不是均匀抽样：单书题数为 3–22 条。新增题目主要来自文字提取较稳定、事实可定位的图书片段，因此本结果不应被解读为对每一本书的等权质量结论。

## 方法

每条问题先使用同一批 Top-15 候选，分别记录初检排序前 5 项和本地 bge-reranker-base 重排后的前 5 项。脚本要求重排结果存在 rerank_score；模型未加载而规则回退时会报错，不产生“开启 rerank”的指标。

比较的初检路径：

1. 项目实际 MultiSourceRetriever 的关键词路径，不注入向量模型；
2. 独立 BM25 基线。

两条路径分别计算，不能互称。本轮没有活动图书语料的 BGE-M3 全量向量索引，也没有向量或 RRF 指标。纯检索与重排没有接入 Gap Detector，因此库外题不执行拒答判断。

## 实测结果

完整逐题候选、排序、指标和耗时见 [120 题报告](../data/evaluation/reports/retrieval-books-v1-rerank-20261005-120.json)。以下 Recall 和 MRR 的分母均为 100 条可回答题：

| 初检 | Rerank | Recall@1 | Recall@3 | Recall@5 | MRR | Top-15 候选召回 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 项目关键词 | 关闭 | 61/100（61.0%） | 77/100（77.0%） | 81/100（81.0%） | 0.692 | 85/100（85.0%） |
| 项目关键词 | 开启 | 80/100（80.0%） | 85/100（85.0%） | 85/100（85.0%） | 0.823 | 85/100（85.0%） |
| BM25 | 关闭 | 79/100（79.0%） | 85/100（85.0%） | 89/100（89.0%） | 0.826 | 95/100（95.0%） |
| BM25 | 开启 | 85/100（85.0%） | 95/100（95.0%） | 95/100（95.0%） | 0.897 | 95/100（95.0%） |

Rerank 对项目关键词路径的 Recall@1 带来 19.0 个百分点提升，BM25 路径的 Recall@5 提升 6.0 个百分点。重排只能在候选池内调整：关键词路径有 15 条、BM25 有 5 条可回答题的金标准不在 Top-15，无法被 rerank 找回。

按题目类型拆分，开启 rerank 后：

| 初检 | 直问 Recall@1 / Recall@5 | 改写 Recall@1 / Recall@5 |
| --- | ---: | ---: |
| 项目关键词 | 85.0% / 86.7% | 72.5% / 82.5% |
| BM25 | 93.3% / 98.3% | 72.5% / 90.0% |

改写题的首位命中低于直问题，说明目前高分部分受资料词面匹配影响，不能作为线上真实问答准确率。

20 条库外题在四种排序结果中均为 0/20 正确拒答，因为本轮只运行检索和重排，不执行拒答模块。这一数字只说明该评测脚本没有做拒答，不能评价完整工作流中 Gap Detector 的效果。

## 限制与后续工作

- 题目由同一人阅读片段后编写，部分来源书的题目较多；应由第二位标注者独立核对，并补齐各书的均衡难题。
- 每题当前只标注一个金标准片段，其他同样可接受的证据可能被漏标。发现其他证据后不应在看过排序结果后回填，应先冻结新的多证据标注规则。
- 题目来自当前图书正文，且 60/100 为直问；它们不能代表真实用户问题分布。
- 本轮没有 BGE-M3 全量向量索引、RRF、生成回答正确率、真实数据库/LLM 集成或 Gap Detector 拒答评测。
- 历史 40 条探索性报告保留在 [原报告](../data/evaluation/reports/retrieval-books-v1-rerank-20261005.json)，它使用不同题集，不能与本表直接比较。

## PowerShell 复现

在项目根目录、活动语料哈希一致的环境中运行：

```powershell
$env:HF_HUB_OFFLINE = '1'
$env:TRANSFORMERS_OFFLINE = '1'

python -m pytest tests/test_books_rerank_evaluation.py -q -p no:cacheprovider
python -m src.evaluation.run_books_rerank `
  --dataset data/evaluation/retrieval-books-v1.jsonl `
  --output data/evaluation/reports/retrieval-books-v1-rerank-local.json `
  --candidate-k 15 --top-k 5

Get-FileHash data/local_books_corpus/documents.jsonl -Algorithm SHA256
```
