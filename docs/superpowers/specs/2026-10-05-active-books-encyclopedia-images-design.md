# 活动图书语料百科配图设计

## 目标

为当前活动图书语料中的百科项目提供来自原始书籍的配图。图片必须能追溯到源书与页码，不能用生成图、网络图或无依据的猜测图替代。

## 范围

- 输入：活动语料目录的 `catalog.json`、`craft_metadata.json`，以及其中记录的十本原始 PDF/EPUB 图书。
- 输出：活动语料目录内的图片资产清单和本地图片文件；每条图片记录包含项目 ID、源书、页码、裁切方式、文件路径与状态。
- 消费方：`ActiveBooksProjection` 的百科列表与详情接口，以及现有百科图片组件。
- 不修改或删除旧图片清单、旧数据库内容和原始书籍。

## 图片选择

1. 对每个项目的来源证据页读取原始 PDF 页面。
2. 优先提取该页的嵌入式图片；过滤极小图标、透明遮罩和重复资源，选择面积最大的有效图片。
3. 页面为整页扫描或没有可用嵌入图时，渲染该页并从版面中裁出主要视觉区域。
4. 若无法得到可用裁图，保存书页缩略图作为回退；若页面也无法渲染，则明确标记为 `unavailable`，不虚构配图。
5. 一个项目可存多张候选图，但公开百科默认使用第一张通过质量检查的图。

## 数据流

`craft_metadata.sources`（书名、页码）
→ 图片资产构建器
→ `local_books_corpus/images/` 与 `book_images.json`
→ `ActiveBooksProjection` 返回 `image.url`、状态与来源信息
→ 百科列表卡片、百科详情页。

图片接口使用本地静态资源路径。图片来源信息会同时保留在接口响应中，供详情页后续展示“来自哪本书、第几页”。

## 可恢复性与质量控制

- 以项目 ID 作为任务键，每完成一张图片立即写入资产清单；中断后跳过已经完成且文件校验通过的条目。
- 资产清单记录输入书籍 SHA-256 与图片文件 SHA-256；书籍版本变化时对应图片重新生成。
- 对每个候选图检查可读取性、最小尺寸、像素面积和重复哈希；失败项记录原因。
- 构建过程只新增资产，不重写已有文本语料和元数据。

## 验证

- 单元测试：嵌入图优先、扫描页裁图回退、不可用状态、断点续跑、同项目图片与证据页一致。
- API 测试：有图片的项目返回可访问本地 URL；无图片的项目仍返回显式 `unavailable`。
- 前端测试：百科列表和详情均渲染同一图片 URL；图片加载失败继续显示现有占位状态。
- 实际抽样：检查不少于 20 个图典项目，确认项目名、图片内容与书页来源一致。
