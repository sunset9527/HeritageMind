# HeritageMind 首页与百科视觉升级设计

## 目标

把现有 Vue 前端从“暖色工具页”升级为有明确非遗工艺语汇的知识平台，同时保留检索、问答、图谱和会话入口的清晰性。首批交付聚焦首页和技艺百科列表；问答、图谱、媒体和账户流程不改变行为。

## 已确认的视觉方向

- 主视觉采用景泰蓝的“铜丝为骨、珐琅成彩”：石青/珐琅蓝作为深色承托，鎏金线条作为纹样，朱砂印章承担品牌强调色。
- 宣纸暖底和极淡纤维纹理提供留白，不用大面积仿古贴图遮挡内容。
- 标题、技艺名和竖排工艺语使用 `Zhi Mang Xing` 行书；正文、导航、表格和数据保持 `Inter`/系统中文无衬线，避免全文书法化造成难读。
- 图案只能服务分区、边框和视觉焦点；搜索、资料入口、可访问文本和按钮拥有更高层级。

视觉确认稿保存在 `.superpowers/brainstorm/homepage-20260914/`，该目录只用于设计沟通且已忽略，不提交。

## 首页结构

1. **品牌导航**：朱砂印章 Logo、现有路由入口和登录状态保持不变；窄屏改为可折叠导航，避免导航文字挤压。
2. **寻艺首屏**：左侧为行书标题、简短平台说明和可提交的问题输入框；右侧用本地技艺图片、半透明色彩叠层与铜丝纹样构成视觉锚点。输入提交时复用现有 `chatStore.setPendingQuestion()` 并路由到 `/chat`。
3. **知识质量带**：展示 `/crafts` 的动态技艺数量和 `/documents/summary` 的动态文档数；检索评测集数量不写成动态运行指标，改为“评测集持续验证”的说明与评测文档入口，防止数字随数据变更而失真。
4. **技艺入口**：展示 API 返回的前四项技艺；每张卡使用已有 `public/crafts/{名称}.jpg`，无法加载时以色块和名称降级。点击进入百科详情，而不是自动向模型发问。
5. **能力入口**：将问答、百科、图谱三项能力设计为正文下方的明确导航卡；不再使用 emoji 作为结构图标。

首页不承诺“热门知识”“最近访问”或“知识贡献排行”，因为当前 API 没有对应的真实数据来源。

## 百科列表结构

- 顶部保留行书页名、总条目数与简明说明。
- 列表为响应式卡片网格：本地图片、技艺名称、服务端返回的摘要和“阅读条目”链接。
- 图片只作入口提示，名称和摘要始终以 HTML 文本呈现；图片加载失败时不会隐藏卡片内容。
- 卡片不伪造来源状态。详情页的逐条来源展示是后续数据接口工作，当前版本只呈现已有百科 API 返回的字段。

## 数据与错误边界

- `getCrafts()`、`getDocumentSummary()` 与 `listEncyclopedia()` 均保留现有异常捕获；任何一个请求失败时，以安全的默认文案或静态骨架显示，不阻止其他区块使用。
- 首页只渲染 API 实际返回的数量；不把“23 项”“46 条资料”硬编码为实时统计。开发时当前文档加载器返回的统计应以接口为准。
- 不引入新的后端接口，不在本次视觉升级中声称百科详情含逐条引用。

## 无障碍与响应式

- 可点击卡片使用语义化 `router-link`；搜索输入具有可见标签或 `aria-label`。
- 颜色不作为唯一状态信息；金色纹样与朱砂按钮在宣纸背景上保持可辨识的文字对比度。
- `prefers-reduced-motion` 下停止轮播和装饰动画。
- 在 375px、768px 和 1280px 下验证：首屏改为单列，指标带与卡片网格按空间换行，文本不依赖竖排才能理解。

## 验收

- 首页和百科页使用统一的行书/无衬线字体分工、纸墨色和铜丝纹样。
- 首页搜索可把问题带到现有问答页；百科卡可打开现有详情页。
- 后端接口失败、技艺图片缺失和窄屏下页面仍可读、可导航。
- `npm run build` 通过；在后端已启动时对首页和百科接口作手动冒烟验证。
- 为新增的首页数据适配与降级逻辑添加前端测试；如果项目没有测试运行器，先补最小的 Vitest 配置和一条真正覆盖路由/降级逻辑的测试，再写实现。
